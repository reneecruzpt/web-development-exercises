Main Web Development languages

HTML (HyperText Markup Language - hypertext markup language) is a standardized markup language for web pages on the World Wide Web. It is a special markup language that is used when creating websites on the Internet. All browsers understand HTML and can display the content of the page, focusing on the markup made using HTML tags.
CSS (Cascading Style Sheets — Cascading style sheets) is a formal language for describing the appearance of a document (web page) written using HTML. CSS is used by web page creators to describe colors, fonts, styles, the location of individual blocks and other aspects of the presentation of web pages in a browser window.
