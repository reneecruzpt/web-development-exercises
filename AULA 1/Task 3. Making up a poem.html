Ranking of programming languages and IT professions

IEEE has published a new ranking of programming languages

The IEEE Spectrum Institute of Electrical and Electronics Engineers recently released its 2020 Programming Language Rankings, traditionally led by Python.

List of three finalists:

  1. Python
  2. Java
  3. C

More information about the ranking can be found here..

List of the most popular professions in the IT field

The study was conducted based on descriptions of more than 300,000 IT vacancies in cities with a population of over one million, published in 2016-2018.

List of professions:

  • Programmer
  • Tester
  • System administrator
  • System architect
  • System analyst

This list is based on the article "The Top Programming Languages, Ranked by Job Demand, Popularity, More"..
